# importador-backup-oauth

Repositório público destinado exclusivamente às páginas informativas necessárias
para configurar o OAuth do Rclone com o Google Drive, usado no sistema de backups
criptografados (Restic + Rclone) do Importador.

Conteúdo previsto:

- Página inicial do aplicativo.
- Política de Privacidade.

Este repositório não contém código-fonte do sistema, credenciais, tokens ou
arquivos de configuração sensíveis.
